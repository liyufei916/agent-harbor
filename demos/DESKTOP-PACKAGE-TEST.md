# 桌面打包端到端测试用例（macOS）

面向 **`wails3 task darwin:package` 产物** 的人工验收清单。对应全量 PAGE（`feat/page-design-full` / 已合入 `main` 的能力）。

## TC-01 打包二进制

**前置**：已安装 `wails3@v3.0.0-beta.34`，`$HOME/go/bin` 在 PATH。

```bash
source ~/.zshrc
cd /Users/he.s/he.s_claude/docs/agent-harbor   # 或本机仓库根
wails3 task darwin:package
```

| # | 步骤 | 期望 | 结果 |

| 1.1 | 执行上述打包命令 | 无致命错误结束；生成 `.app` | ☐ |

### 7.9 安全副本 ↔ 原项目文件对比

**前置**：`mountMode=clone`；工作区建议 `demos/workspace` 绝对路径；工作台已显示 **原目录**（`sourceWorkspace`）与 **副本目录**（`workspace`）。勿用含密钥的真实业务目录。

**记号**（从工作台元信息复制，勿手猜）：

```text
原目录 ORIG=……
副本目录 CLONE=……
基线探针文件（任选其一）：ORIG/hello.txt 或 ORIG/summary.txt
```

**对比命令（本机终端，勿贴进会话任务）**：

```bash
# 目录树差异（忽略常见噪音时可加 -x）
diff -rq "$ORIG" "$CLONE" | head -50

# 单文件内容对比
diff -u "$ORIG/hello.txt" "$CLONE/hello.txt" || true
shasum -a 256 "$ORIG/hello.txt" "$CLONE/hello.txt"
```

| # | 步骤 | 期望 | 结果 |
|---|---|---|---|
| 7.9.1 | 开跑 **前** 记录探针文件内容/哈希（或确认 `hello.txt` 初始态） | 有可复现基线；ORIG 与即将克隆内容一致 | ☐ |
| 7.9.2 | 会话 running 后立即 `diff -rq "$ORIG" "$CLONE"`（Agent 尚未改文件） | 副本为原目录快照：常规文件应对齐；允许元数据/空目录等细微差，**无业务文件内容漂移** | ☐ |
| 7.9.3 | 工作台下达任务：仅在工作区内创建或修改探针文件（如改写 `hello.txt` / 新建 `harbor-clone-probe.txt`） | Agent 成功；审计/输出可见；**改动落在 CLONE** | ☐ |
| 7.9.4 | 再对比：`diff -rq` / 单文件 `diff` / `shasum` | **CLONE 已变**；**ORIG 探针文件哈希仍与 7.9.1 基线一致**（原项目未被改） | ☐ |
| 7.9.5 | 在 ORIG 侧用访达/终端**手动**改一个旁路文件（或临时加 `ORIG/outside-agent.txt`） | 副本侧**不自动出现**该改动（clone 非实时双向同步） | ☐ |
| 7.9.6 | 工作台点 **导回原文件夹**（`SyncBackWorkspace`） | 成功提示；无崩溃 | ☐ |
| 7.9.7 | 导回后对比探针 | Agent 在副本改过的文件 **已合并进 ORIG**（同名覆盖）；7.9.5 若在 ORIG 独有的文件 **仍保留**（导回不删原目录多余文件） | ☐ |
| 7.9.8 | （可选）停止 → 销毁会话后再查 CLONE/retained | 销毁后会话副本/保留目录按产品约定清理；ORIG 保留导回结果 | ☐ |
| 7.9.9 | （对照）另开 **direct** 会话改同一探针 | 改动直接出现在 ORIG；与 clone「先副本后导回」行为可区分 | ☐ |
